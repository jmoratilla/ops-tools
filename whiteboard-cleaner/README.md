# White Board Cleaning Tool


This is a small script cloned from [lelandbatey](https://gist.github.com/lelandbatey/8677901?permalink_comment_id=1205843),
where you can pass an image about a whiteboard or white paper with drawings and get a clear view of the drawing ready to print.

It's very handy and kudos to @lelandbatey for his work.
